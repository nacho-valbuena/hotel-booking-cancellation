# Dataset

Este proyecto utiliza el dataset **Hotel Booking Demand**.

Fuente: https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand?resource=download

Descargá el archivo `hotel_bookings.csv` desde Kaggle y colocalo en la ruta esperada por el notebook antes de ejecutar el proyecto.

El dataset no se versiona dentro de este repositorio para mantener el repositorio liviano y documentar explícitamente su fuente de acceso.
